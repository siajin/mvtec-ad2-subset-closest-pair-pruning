# 공개 범위와 이용 조건

2026-11-12 공개본은 CP100 연구 설명, 자체 연구 코드의 선별 snapshot과 portable adapter, 수치 결과표, 통계 그림으로 구성한다. 원본 실험·실패 진단·승인 기록을 수정하지 않았다.

이미지·GT·특징 cache·대표 벡터 bank·모델 가중치·개별 score map, 개인 계정 경로, SSH/API 인증정보, 과금·pod 운영 로그는 게시하지 않는다. Provenance는 개인 절대 경로 대신 논리적 root와 상대 경로를 사용한다.

MVTec AD 2 데이터는 [공식 이용 조건](https://www.mvtec.com/research-teaching/datasets/mvtec-ad-2)에 따라 별도로 받는다. DINOv3·PatchCore·SuperADD 등 외부 코드와 모델에는 원 프로젝트 조건이 적용된다. 외부 프로젝트 전체 소스를 vendoring하지 않았다.

이 공개본의 자체 코드·문서에 대한 별도 오픈소스 license grant는 아직 지정하지 않았다. GitHub public 공개와 MIT/Apache 등의 재사용 허가는 구분한다. 인용 정보는 [CITATION.cff](../CITATION.cff)에 있다.
